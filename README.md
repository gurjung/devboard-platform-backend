# DevBoard Backend

Standalone REST API backend for the DevBoard workspace and project management platform.

## Tech Stack
- **Runtime:** Node.js
- **Framework:** Express
- **Language:** TypeScript
- **Database:** PostgreSQL
- **ORM:** Prisma

## Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- PostgreSQL instance

### Installation
```bash
npm install
```

### Environment Setup
Copy `.env.example` to `.env` and fill in the required values:
```bash
cp .env.example .env
```

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
npm start
```
